Zero-Manual Effort

Automate via GitHub PR Webhooks

Have CogniReview automatically comment on your team's pull requests without opening any website.

STEP 1

Go to Repository Settings

In your GitHub repository, navigate to Settings ➔ Webhooks ➔ Add webhook.

STEP 2

Paste Webhook Payload URL

Set Payload URL to: http://your-server:4000/api/webhooks/github

STEP 3

Select "Pull Requests" Event

Check Let me select individual events ➔ Pull requests and save. CogniReview will now review all new PRs!
